## 原文来源和筛选

导出程序以只读模式查询本机 Codex 的 `state_5.sqlite`，仅按上述四个明确聊天 ID 查找会话日志，再核对工作目录和用户主聊天类型。程序随后读取相应的 UTF-8 JSONL 会话日志；不会修改原始数据库、日志，也不读取身份验证文件或配置文件。

每条记录只取 `response_item` 中的 `message`，不重复采集事件投影。用户消息必须带有 `user.text` 元数据；助手消息仅取 `commentary` 和 `final_answer`。系统提示、开发者提示、内部分析、工具参数、工具输出、子代理通信和自动生成的环境上下文均不导出。

保留正文的原文字句及 Markdown。传输包装和自动浏览器状态已移除。用户对异步问题的回复以“问题”“回答”展开，保留这两个字段的原文，并去除工具调用标识。通过工具展示的助手提问没有另行作为工具参数导出；对应问题可在用户回复中阅读。

## 快照、附件和链接

- 每份聊天文件记录导出时间、可见消息起止时间、聊天 ID 和消息计数，统一使用上海时间（UTC+08:00）。
- 当前 GitHub 协作聊天正在运行，导出仅为文件头所示时刻已落盘内容的快照，不包含此后的消息。其他聊天也可能继续产生消息，最后一条回复不一定表示聊天永久结束。
- 用户在比赛选题聊天中提供了四张图片。本次不复制或下载附件，不导出嵌入的 `data:image` 等媒体数据；图片位置使用明确占位。图片内容不能仅凭这些 Markdown 文件还原，需在原聊天查看。
- 原文中的本地文件路径、Excel 或其他生成文件链接仅作记录。这些文件没有随本次对话导出自动打包，GitHub 无法直接访问本地路径；需要共享时应另行核对并上传相应文件。
- 原文中的建议、引用和判断是聊天当时的内容，本次仅作归档，没有重新核实或更新。

## 手工更新

程序仅使用 Python 标准库，默认读取当前 Windows 用户的 `.codex` 目录。运行时不需要密码，也不会执行 GitHub 上传。

```powershell
python .\export-conversations.py --output .\snapshots\2026-10-21
```

默认拒绝覆盖已有聊天文件，可选择新的快照目录保存。确需替换时使用明确的 `--overwrite`；它会替换这四份聊天导出中的手工改动，因此应先通过 Git 保存需要保留的编辑。

```powershell
python .\export-conversations.py --overwrite
```

程序结束时输出各文件的消息数量、时间范围、附件占位数量及疑似凭据的位置。凭据检查只是格式识别，不构成内容完整性或无敏感信息的保证；程序不会打印匹配到的凭据值。
